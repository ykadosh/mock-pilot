# mock-pilot

An Electron desktop application built with:

- **Electron** + **Electron Forge** (packaging & development)
- **Vite** (bundler)
- **React** + **TypeScript** (renderer)
- **Tailwind CSS** + **shadcn/ui** (styling & components)

## Development

```bash
npm start
```

## Package

```bash
npm run package
```

## Make (distributable)

```bash
npm run make
```
